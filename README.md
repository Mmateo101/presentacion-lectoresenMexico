# Desigualdad en el acceso a la lectura ·  Presentación interactiva

This is the presentation for Equipo 7's statistical study (MA1001B, Tecnológico de Monterrey). It plays like an illustrated, animated book: animated scenes alternate with slides that build step by step.

## How to open it

- Double-click `index.html`. It works without internet because fonts, GSAP and D3 are included in the repo.
- Or serve the folder with `npx serve .` and open the address it prints.
- Use Chrome for the best animation quality. For a projector, press **F** for full screen.

## Controls

| Key | Action |
| --- | --- |
| Space, →, PageDown | Next step, or the transition to the next slide when the current one has no steps left |
| ←, Backspace, PageUp | Previous step. It jumps back instantly and does not replay the slide |
| F | Full screen |
| R | Replay the current slide from its first step |
| 1–9, 0 | Jump to a slide (0 = slide 10) |
| N | Show or hide the presenter notes |

Pressing Space while an animation is playing finishes it immediately. The URL keeps the position (`#8.3` = slide 8, step 3), so you can reload without losing your place.

## Structure

```
index.html            shared SVG filters (watercolor, ink) and the script loading order
css/styles.css        palette, paper texture, cards, progress ribbon
css/fonts.css         local fonts (Fraunces, Nunito, Caveat, Pinyon Script)
js/data.js            ALL numbers in the presentation (Section 6 of the script)
js/main.js            engine: stage scaling, steps, navigation, notes
js/lib.js             helpers: text that writes itself, watercolor, counters, strokes
js/characters.js      Héctor, Eduardo and the props, drawn in SVG
js/transitions.js     page turn, ink spreading, watercolor bloom
js/charts/charts.js   D3 charts that reproduce the team's R charts
js/slides/slideNN.js  one GSAP timeline per slide
js/mexico.js          map of Mexico (generated by tools/build_mexico.py)
assets/               Tec logo and fonts
```

Each slide builds a single timeline. `S.step()` marks where each Space press starts. Everything before the first `S.step()` is the slide's entrance, which plays automatically when the slide appears.

## Data note

All numbers come from `js/data.js`. Section 6 of the script did not include the 96% confidence interval for each group in the "Solo escuela vs. solo hogar" chart (slide 8). Those error bars are computed as p ± 2.054·√(p(1−p)/n), as in the team's R chart, and are marked as such in `data.js`. The boxplot whiskers on slide 10 use the R rule (1.5·IQR) applied to the given quartiles.
